---
title: "API Admin/Client"
---

Dwa API do dwóch zadań. Admin API służy Twojemu zespołowi IT do samodzielnych integracji. Client API pozwala systemom Twoich klientów składać zamówienia i śledzić ich realizację bez logowania do sklepu.

- Admin API, głównie do samodzielnej integracji,
- Client API do składania i śledzenia zamówień oraz pobierania cenników i dostępności.
